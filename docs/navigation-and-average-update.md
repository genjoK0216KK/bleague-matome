# ナビ・平均EFF・日付別記事（未公開の変更）

## 最新仕様

2026-10-14の本人追加指示により、次戦ランキングを今季通算から今季平均へ変更。
公式statsは `dt=avg&value=EFFPG`。選択されたシーズン/大会/平均モードとEFFPG列を検証する。
公式平均をそのまま使用し、通算合計÷試合数で丸め直さない。例：オーガスト7試合・34.7。
既存の当日B.PREMIER単試合EFF記事の集計は変更しない。
上位3人、3人目と同点を含める。順位は1,1,3、複数ポジションはそれぞれ掲載、出場試合数を併記。
未取得・移籍合算未確認・G=0を平均0へ置換しない。公式ILの注意と出場未確認表示は維持する。

`article-games-YYYYMMDD.html`を日付の主記事とし、B.PREMIER/B.ONE/B.NEXTを記事内の3節へ分ける。
各試合の予定/結果を表示し、平均ランキングは記事内の折りたたみから読める。
実際のJST試合日で絞り、日程URLのfallbackを対象日の試合と扱わない。取得未完了と試合なしを区別。
`next-games.html`は日付別の記事への入口。既存 `article-preview-*` は詳細URLとして保持する。
旧 `article-results-one-next-*` URLも読める互換ページとして保持するが、記事一覧では新しい日付記事のみ掲載。
取得が不完全で既知試合が欠落する場合は以前の日付記事を保持する。
