# 試合結果の原典照合（設計・未接続）

作成 2026-10-22。`scripts/result_evidence.py` と `tests/test_result_evidence.py`。本番の生成処理には接続していない。

## 目的

公式サイトを直接取得できない間に、別の経路で「結果が公開されている」証拠を見つけた場合の扱いを決める。
証拠は記録して照合するが、本番の確定スコア・BOX SCORE には自動で入れない。

## 記録する項目（1件ごと）

- 取得経路：公式サイトを直接取得／公式サイトの検索インデックス（検索結果の断片）／クラブ公式の通常公開報告
- 時刻は意味ごとに分ける（どれも不明なら「不明」）：
  - published_at：原典に書かれた公開日時（確認できた場合だけ）
  - updated_at：原典に書かれた更新日時（確認できた場合だけ）
  - crawled_at：検索エンジンがその原典を読み込んだ時点（検索結果に出ている場合だけ）
  - retrieved_at：こちらが検索結果・原典を確認した日時
- Asia/Tokyo の絶対日付、試合ID（不明なら空）、対戦の組み合わせ、リーグ、シーズン（不明なら「不明」）
- 得点と状態の表記（FINAL／途中など、原文のまま）

## 判定（state）

| state | 意味 | 得点を確定として出すか |
|---|---|---|
| confirmed_official | **今回**公式の試合ページを直接取得し、既存の確定条件（GameEndedFlg かつ RecordFixedFlg、出典、0以上の整数）を満たす | 出す（従来どおり） |
| previously_confirmed | 保存済みの確定値はあるが、今回は直接取得できていない | 今回の確定とはしない（保存済みの確定値は消さない・書き換えない） |
| official_not_fixed | 公式を直接取得できたが、公式記録はまだ確定していない | 出さない |
| reference_only | 直接取得できず、対象試合を指す記録があり、原典の公開・更新日時が試合開始後と確認できる | 出さない（参考） |
| reference_stale | 対象試合を指す記録はあるが、原典の公開・更新日時が不明または試合開始前（クロール時点が試合後でも、それだけでは終了の根拠にしない） | 出さない（存在の参考） |
| mismatch | 対象試合を指す記録どうしで状態・得点が食い違う（途中とFINALの混在など） | 出さない（照合待ち。途中経過をFINALで上書きしない） |
| unverified | 直接取得できず、対象試合を指す記録も無い | 出さない |

日付・試合ID・対戦・リーグ・シーズンのどれかが合わない記録、試合IDが不明な記録は「対象試合を指す」とみなさない（推測で寄せない）。
